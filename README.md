# 🎬 Movie Analytics Dashboard

An interactive data dashboard built with **Streamlit** and **Plotly**.

## Features
- Filter movies by genre, rating, and year
- KPI cards: total movies, average rating, top rated
- Bar chart, pie chart, scatter plot
- Interactive data table

## Tech Stack
- Python 3.11+
- Streamlit
- Pandas
- Plotly

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
